# Roya News Website

A modern, responsive Arabic news website designed to deliver the latest updates and breaking news from Jordan and around the world. The site features a clean, user-friendly interface with support for right-to-left (RTL) text direction, making it ideal for Arabic-speaking audiences.

## Project Overview

This project is a news portal named **Royana News (أخبار رويانا)** that aims to keep users informed with the latest news in Jordan, Palestine, regional and international affairs, economy, sports, health, technology, and more. The website layout is fully responsive using Bootstrap 5 and is optimized for Arabic RTL display.

---

## Features

- RTL layout fully compatible with Arabic language  
- Responsive navigation bar with multiple news categories  
- Header with welcome message and quick access buttons for login and live broadcast  
- Main news section with featured articles including images, titles, and excerpts  
- Sidebar for latest or important news highlights  
- Image slider showcasing multiple news images  
- Footer with useful navigation links and social media channels  
- Mobile-friendly and adaptive design using Bootstrap 5

---

## Technologies Used

- HTML5  
- CSS3 (custom styles with an external stylesheet)  
- Bootstrap 5 (for responsive layout and components)  
- JavaScript (Bootstrap JS bundle for interactive components)
